# Education

Enrollment, applications, requirements, and learning progress that describe the user's situation. General subject knowledge belongs in the separate Garden.

## Files

| File | Contents | Suggested headings |
| --- | --- | --- |
| `overview.md` | Current enrollment, work, and applications | Enrollment / Current work / Applications / References |
| `programs/program.md` | One enrollment or educational program | Enrollment / Requirements / Progress / Important dates / Sources |
| `applications/year-school.md` | One application and its actual stage | Target / Status / Requirements / Dates / Submitted materials / Open loops / Sources |
| `learning/course.md` | Progress through a course or learning activity | Purpose / Current progress / Resume from / Materials / Recent |

Create subdirectories only when useful. Use an application-cycle label to distinguish repeat applications. Link to grades or submitted materials when relevant instead of copying every original record.

## Example: an application page

This is a scaffold, not an actual application or a set of application requirements.

```markdown
# Example University — application cycle

## Target

Program and admission route, as selected by the user.

## Status

Current stage and verification date. Distinguish registered, submitted, and received.

## Requirements

Requirements confirmed in the official instructions, with source references.

## Dates

Confirmed deadlines and interview times, with timezone when relevant.

## Submitted materials

Submission date and references to the versions actually submitted.

## Open loops

Remaining preparation or unconfirmed receipt. Link to the existing task tracker.

## Sources

Official instructions, receipt messages, and submitted documents.
```

## Updating

Follow [the shared update rules](../AGENTS.md). Preserve source-backed dates and status changes. A planned application is not a submitted application. For learning, a short “resume from” note is useful; do not require ongoing note-taking or duplicate course materials here.
