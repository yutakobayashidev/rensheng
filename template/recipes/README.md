# Recipes

Personal cooking instructions used in daily life, including adaptations that work for the user. General culinary knowledge belongs in the separate Garden.

## Files

Use one file per dish, such as `midnight-aglio-olio.md`. Keep existing names when they are already useful. A recipe index is optional.

Suggested headings: `Ingredients`, `Steps`, `Substitutions`, `Notes`, and `Source`. Add servings or timing only when helpful.

## Example: a recipe page

This scaffold describes what to record; it is not a completed recipe.

```markdown
# Dish name

## Ingredients

Amounts for the portion the user actually makes.

## Steps

The user's practical sequence, including useful equipment or timing details.

## Substitutions

Alternatives the user has tried. Distinguish untested suggestions if retained.

## Notes

Adjustments, preferences, or pitfalls the user wants to remember.

## Source

Reference to the original recipe where applicable.
```

## Updating

Follow [the shared update rules](../AGENTS.md). Keep useful changes to the procedure; no rating or review is required after cooking. Preserve personal adaptations and link to source recipes rather than copying an entire external article.
